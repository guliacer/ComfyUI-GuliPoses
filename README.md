[![Poses](https://img.shields.io/badge/图库-288%20组%20%C2%B7%201439%20张-ff6b6b)](#数据)

**在 ComfyUI 节点里直接翻姿态图库、选好姿态和视角就出图。**

白模（3D mannequin 线稿）姿态参考图库节点。288 组人体姿势 × 5 个视角，全部内置在节点画廊里，不用离开画布去翻文件夹，也不用手写图片路径。输出直接接 ControlNet / Depth / Lineart。

支持三种取图方式：**固定选中**（精确复现）、**全库随机**（抽卡）、**范围内随机**（只在指定系列 / 分类里抽）。

## 为什么用它

| | |
| --- | --- |
| **不出画布** | 缩略图栅格就在节点里，点一下即选中，节点自动跟着你的宽度伸缩 |
| **三种取图方式** | 想精确复现就固定选中，想抽卡就全库随机，想只在小范围里抽就范围内随机 |
| **随机也看得见结果** | 跑完节点会把真正抽中的姿态推回画廊，自动跳到那一张——不是「随机了但不知道抽了啥」 |
| **抽到就锁定** | 随机抽到满意的那张，点一下缩略图就切成固定选中，工作流里存的就是它——不需要记种子 |
| **零额外依赖** | 只用 ComfyUI 环境自带的 PIL / numpy / torch，不引入 cv2、kornia 之类重包 |
| **中文界面** | 参数名、输出名、模式、视角、系列、分类、姿势名全是中文，不夹英文参数名和日文原文；深/浅主题都跟随 ComfyUI 的 CSS 变量 |

## 安装

把整个 `ComfyUI-GuliPoses` 目录放进 `ComfyUI/custom_nodes/`，重启 ComfyUI。

```
ComfyUI/
└── custom_nodes/
    └── ComfyUI-GuliPoses/     ← 放这里
        ├── nodes.py
        ├── pose_db.py
        ├── api_routes.py
        ├── web/
        ├── poses/             ← 图库资源（见「数据」一节）
        └── tools/
```

装完在画布空白处右键 → 新建节点 → **GuliPoses** → **GG 姿态库**。

> 首次安装需要准备图库资源（`poses/` 目录，约 368 MB），见 [数据](#数据) 一节。

## 节点

**GG 姿态库**（`GuliPosePicker`，分类 `GuliPoses`）

界面全中文：参数名、输出名、系列 / 分类 / 姿势名一律中文，不出现英文参数名和日文原文。

### 输入

| 参数 | 类型 | 生效模式 | 说明 |
| --- | --- | --- | --- |
| 模式 | 下拉 | 全部 | 固定选中 / 全库随机 / 范围内随机 |
| 姿态 | 下拉 | 固定选中 | 288 个姿态，形如 `性感全身 P001 · S形站姿・胯部侧顶` |
| 视角 | 下拉 | 全部 | 正面 / 俯视 / 仰视 / 侧面 / 斜侧 / **随机视角** |
| 筛选系列 | 下拉 | 范围内随机 | 全部 + 四个系列（按姿态数降序） |
| 筛选分类 | 下拉 | 范围内随机 | 全部 + 26 个分类（按姿态数降序） |

只有五个参数，没有 `seed`、也没有 ComfyUI 给种子附加的「生成后控制」——这个节点不参与采样，种子对它没有意义。

**参数跟着模式走**：选中哪个模式，节点只露出该模式下真正生效的参数，其余自动隐藏。所以固定选中时你看到的是干净的三行（模式 / 姿态 / 视角），全库随机只剩两行，不会有一排用不上的灰条。

**节点高度由你决定，不会被代码改回去**：把节点拉高，画廊跟着变高、栅格多显示几行；拉过的尺寸会写进工作流，切模式、切视角、换筛选都不会把它吸回去——少掉的那几行参数自然由画廊吃掉。只有 `Ctrl+V` 导入完这类需要露出新内容的时候才会往大里补，绝不往回缩。

> 隐藏只是不画出来，`widgets_values` 的顺序和长度不变，工作流照样能存能读，后端拿到的参数也完全一致。
> 参数名本身就是中文，没有「英文标识符 + 中文显示名」的映射层，`/prompt` 里看到的就是这几个中文键。

### 输出

| 输出 | 说明 |
| --- | --- |
| 姿态图 | 选中的姿态图，`900×1200` RGB，0–1 浮点，bat |

只输出图。姿态名与视角在画廊徽标上就写着，不需要再拉两根字符串线出来占地方。

## 三种取图模式

### 固定选中（默认）

按「姿态」+「视角」精确取图。画廊里点缩略图、点视角按钮都会同步到这两个下拉框，选择随工作流一起保存——打开旧工作流还是原来那张。

适合：已经想好要什么姿势，或者要复现某次结果。

### 全库随机

在全部 288 个姿态里抽一个。此时「筛选系列」「筛选分类」被忽略，画廊里的系列下拉会变灰。

适合：批量探索、给一批图随机换姿势。

### 范围内随机

在「筛选系列」×「筛选分类」交出的候选集里抽一个。两个筛选都支持「全部」，所以「只限某系列」「只限某分类」「两者取交集」用的是同一套参数。

适合：做某个题材的系列图，既要有变化又不能跑出范围。

> **筛选口径**：先按系列取子集，再看该子集里有没有这个分类；没有就退到「只按系列」，系列也是空的才退全库。
> 所以选到空组合不会报错，但会**静默放宽范围**——画廊底部的「候选 N 个」显示的始终是后端真正会用的池子大小，跟着它走就不会意外。

### 视角

六个选项：**正面 / 俯视 / 仰视 / 侧面 / 斜侧 / 随机视角**。选「随机视角」时在该姿态**实际拥有**的视角里抽。

### 没有种子，怎么固定结果

随机模式下每次都是真随机，不存种子。想留住某次结果，**直接在画廊里点那张缩略图**——模式会切回固定选中，姿态与视角一起写进工作流，之后每次跑都是它。

这比记种子直观：你看到的就是你要的，点一下就在了。

### 执行后回传

三种模式下，执行完节点都会把真正抽中的姿态推回前端，画廊自动跳到那一张、徽标更新为真实结果。

> 随机模式每次排队都会重新抽（节点声明了 `IS_CHANGED`，不会被缓存挡住）；固定选中则正常走缓存，同一张图反复跑不会重复读盘。

## 画廊

节点下半部分是一个自绘的 DOM 画廊，从上到下六层：

| 层 | 内容 | 操作 |
| --- | --- | --- |
| 大图预览 | 当前选择，左下角徽标 `编号 · 分类 · 视角` | — |
| 视角栏 | 正面 / 俯视 / 仰视 / 侧面 / 斜侧 | 点一下，整栅格缩略图跟着换成该视角 |
| 工具行 | 系列下拉 · 搜索框 · 「导入」 · 「随机」按钮 | 筛选 / 检索 / 导入自己的图 / 在当前可见范围里挑一个 |
| 缩略图栅格 | 列数随节点宽度自适应；末行只剩一张时自动均分重排 | 点一下即选中 |
| 页脚 | 左边候选数，右边当前模式提示 | — |
| 推荐行 | 一行小字指向配套插件 | 点击打开 ComfyUI-GuliNodes 仓库 |

- **系列下拉** — 按系列过滤画廊；随机模式下它直接控制候选范围
- **搜索框** — 匹配编号、姿势名、分类、label
- **导入** — 把自己的姿态图放进库里，详见 [导入自己的姿态图](#导入自己的姿态图)
- **随机按钮** — 在**当前可见范围**里挑一个，并切回固定选中。它不是「记住一个种子」，而是直接把那张图钉进工作流
- **随机模式的画廊** — 直接显示候选池，格数与底部「候选 N 个」始终一致
- **陈旧预览** — 随机模式下如果预览图不在当前候选范围里（比如刚改了筛选），图片会压暗、徽标前缀变成「上次 · 」

> 姿态编号在不同系列里会重复（`P001` 有四个系列各一份），所以「姿态」下拉框的选项带系列前缀。

## 数据

图库共 **288 组姿态 × 5 个视角 = 1439 张图**（`full_sexy_P018` 缺「仰视」，选到该角度时自动回退到正面）。

| 系列 | 姿态数 |
| --- | --- |
| 全身单人-性感系 | 80 |
| 上半身单人 | 80 |
| 全身单人-标准系 | 73 |
| 双人互动 | 55 |

26 个动作分类（站姿 / 趴卧 / 坐姿 / 跪立・四肢着地 / 贴脸系 …），分类名与姿势名**已全部译成中文**，日文原文保留在 `catJp` / `nameJp` 字段里备查。

```
data/zh-dict.csv  # 日→中对照表（323 条：288 姿势名 + 26 分类 + 5 视角 + 4 系列）
poses/
├── img/        # 全尺寸 900×1200 PNG（343 MB）
├── thumbs/     # 300×400 缩略图（26 MB），画廊用
├── custom/     # 自己导入的姿态图，扫目录时自动并入索引
└── index.json  # 索引，由 tools/build_pose_db.py 生成
```

图片体积大，不进版本库（见 `.gitignore`）。获取方式见下方 [致谢](#致谢) 里的来源仓库，把 `img/`、`thumbs/` 复制进 `poses/` 后跑一次索引脚本：

```bash
python tools/build_pose_db.py "D:\path\to\pose-db-01"
```

脚本读 `data/poses.csv` 重建 `poses/index.json`，并按 `data/zh-dict.csv` 把分类与姿势名译成中文。对照表缺失时会自动退回日文原文，并在结尾报出未命中的条目数。索引按文件修改时间自动重读，重建完不用重启 ComfyUI。

## 导入自己的姿态图

点工具行的 **「导入」** 选图、**把图片拖进面板**，或者复制一张图后在画布上按 **Ctrl+V**，都会弹出导入对话框；确认后存进 `poses/custom/`，扫目录时自动并进索引——**不用重建内置库，也不用重启 ComfyUI**。

对话框里可以做三件事，都是为了让你不用回头改文件名：

| 字段 | 作用 |
| --- | --- |
| 名称 | 这张图的显示名（默认取文件名）。多张图共用一个名称时会自动编号「名称 1」「名称 2」… |
| 分类 | 归到哪个分类，可以从已有分类里选，也可以直接输入一个新分类 |
| 视角 | 这张图是正面 / 俯视 / 仰视 / 侧面 / 斜侧 |

- **一个文件 = 一个视角**；**同名 + 不同视角 = 同一个姿态的不同视角**，画廊里合成一格，切视角就能看到
- 同名 + **同视角** 不会覆盖：会另存为新姿态「名称 (2)」，两张图都留着
- 对话框里还有 **「从剪贴板」** 按钮，读系统剪贴板里的图片；浏览器不给权限时会提示改用 Ctrl+V
- 名称留空就用文件名；归到系列 **我的姿态**，在画廊里排最前面
- 缩略图由插件自己生成（长边 320，透明底铺白），存在 `poses/custom/thumbs/`，不用自己压
- 导入后下拉框**就地刷新**：固定选中模式下会自动选中刚导入的那张，并切到它实际拥有的视角；随机模式下只是把它加进候选池，不动你当前的选择
- **右键点自定义缩略图可以删掉它**，该姿态的所有视角图会一起从 `poses/custom/` 移除（删了找不回来，会先弹确认）
- 支持 `png / jpg / jpeg / webp / bmp`；文件名里的路径与非法字符会清掉，中文原样保留
- 手动往 `poses/custom/` 里丢文件也行，刷新页面就能看到；坏图会在 ComfyUI 控制台里报出名字并跳过

```
poses/
└── custom/        # 你的姿态图，一个文件一个视角
    ├── thumbs/    # 自动生成的缩略图，别手改
    └── meta.json  # 名称 / 分类 / 视角的对应表，别手改
```

自定义姿态和内置库共用同一套筛选与随机：系列选「我的姿态」、分类选「自定义」就能单独圈出来，全库随机时也会抽到。显示名存在 `meta.json` 里，所以**改显示名后旧工作流里存的旧名字会对不上**，节点会提示重新选一个。

## 搭配推荐

### 想要更多功能？装 [ComfyUI-GuliNodes](https://github.com/guliacer/ComfyUI-GuliNodes)

本插件只做一件事：**把姿态图库搬进画布**。如果你在日常出图里还缺下面这些东西，直接装配套的 **ComfyUI-GuliNodes** —— 面向中文工作流的轻量效率节点合集，**38 个节点，零额外 Python 依赖**，和本插件不冲突、可共存。

| 你想要的 | GuliNodes 里对应的 |
| --- | --- |
| 画布一团乱，节点对不齐 | 顶部工具栏：上色、对齐、等宽等高、自动间距、批量整理；分组可折叠成子工作流小节点 |
| 总在算 1024×1536 该怎么对齐到 8 | `GG 图像宽高` / `GG Latent`：按边长、按 K 数分辨率、按 Latent、按图像四种方式取尺寸 |
| 想批量裁剪、缩放、调色、对比 | `GG 图像裁剪` / `GG 图像缩放` / `GG 图像调整` / `GG 色彩校正` / `GG 图像对比 N张` |
| 提示词写不动 | `GG 提示词增强qwen2.1`（API / 本地 PE / 本地 LLM 三种方式）+ `GG 提示词优化qwen2.1` |
| 想要个能藏 API Key 的地方 | `GG 密钥输入`：端点 / Key / 模型名，可测试连通性、拉模型列表 |
| 显存吃满、模型不卸载 | `GG 内存清理`：卸载模型 + 清缓存 + 输出报告 |
| 处理视频 | `GG 视频加载` / `GG 视频合成` / `GG 视频压缩` / `GG 视频保存`（需系统可调 `ffmpeg`） |
| LoRA 叠了一堆不好管 | `GG LoRA自定义加载`：最多 20 槽 |

安装：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/guliacer/ComfyUI-GuliNodes.git
```

或在 ComfyUI Manager 里搜索 `ComfyUI-GuliNodes` 安装，重启后强制刷新浏览器（`Ctrl` + `F5`）。装完在右键菜单里找 **GG** 或 **GuliNodes** 分类（注意区分：**GG 姿态库** 是本插件的节点，挂在 **GuliPoses** 分类下，不在 GG 里）。

> 两个插件的分工：**GuliPoses 负责「选什么姿势」，GuliNodes 负责「出图流程本身顺不顺」**。一起装是互补的，不会抢同一个节点名。

## 实现

- `nodes.py` — 节点定义、三种模式分支、`IS_CHANGED` 缓存策略、`ui.picked` 回传
- `pose_db.py` — 索引缓存、`pool()` 候选集与回退链、`pick_angle()`、缺图回退；扫描 `poses/custom/` 并生成缩略图，与内置索引合并
- `api_routes.py` — `/guliposes/index.json`、`/guliposes/thumb|img/{name}`、`/guliposes/custom/thumb|img/{name}`、`/guliposes/custom/upload`、`/guliposes/custom/delete`（只按文件名取，禁止目录穿越；内置图带 7 天缓存，自定义图走协商缓存）
- `web/gg-pose-gallery.js` — DOM 画廊控件（无构建步骤，直接 ES module），随机模式的候选池与后端同口径
- `tools/build_pose_db.py` — 生成索引
- `AGENTS.md` — 开发规范（与 ComfyUI-GuliNodes 同源）：设计自检、命名、显示规则、前端红线、验证流程
- `tools/verify/*.mjs` — 无头 Chromium 验证脚本

### 验证脚本

改完前端或模式逻辑后，起一个**隔离实例**再跑（不要动正在用的那个）：

```bash
python -s ComfyUI/main.py --port 8189 --cpu --disable-all-custom-nodes \
  --whitelist-custom-nodes ComfyUI-GuliPoses --disable-auto-launch
```

```bash
COMFY_PORT=8189 node tools/verify/frontend-modes.mjs    # 筛选交集 / 仅分类 / 全库随机锁下拉 / 序列化恢复
COMFY_PORT=8189 node tools/verify/queue-roundtrip.mjs   # 真实排队：随机两次都重抽、固定第二次命中缓存、ui.picked 回传
COMFY_PORT=8189 node tools/verify/layout.mjs            # 布局体检：无溢出、栅格高度、推荐行可见
COMFY_PORT=8189 node tools/verify/mode-visibility.mjs   # 参数显隐：每种模式只露该露的控件、且节点高度不被改
COMFY_PORT=8189 node tools/verify/custom-import.mjs     # 导入闭环：点导入弹框、改名称/分类/视角、同名合并、剪贴板、右键删除、清场复原
```

五个脚本都依赖本机已有的 playwright-core 与 chromium，路径写在脚本头部常量里。`custom-import.mjs` 会自己造测试图上传再删掉，跑完 `poses/custom/` 应恢复原样。

- 旧工作流兼容：残留的多余输出槽在载入时自动清理；缺失的 `seed` 值被忽略，其余参数按位对应。
- 支持导入自己的姿态图：工具行「导入」、拖进面板或 Ctrl+V 粘贴都会弹导入对话框，可自定义**名称 / 分类 / 视角**；同名不同视角合并成一个姿态，同名同视角自动另存「名称 (2)」。存进 `poses/custom/` 后自动补进下拉、画廊与随机池（系列「我的姿态」），导入后下拉就地刷新、固定模式自动选中新图并切到它的视角，右键可删除。节点参数数量不变，旧工作流照常打开。
- 修掉「点导入没反应」：导入与随机两个按钮曾共用类名，随机逻辑把导入按钮的点击处理器覆盖掉了。
- 修掉「节点高度自己收缩」：画廊改为吃掉节点剩余高度（拉高节点，栅格真的多显示几行），切模式 / 切视角 / 换筛选都不再改写节点高度，拉过的尺寸会被工作流记住；摘旧输出槽时也只补高不压低。
- 索引按修改时间重读，重建内置库后不必重启 ComfyUI。
