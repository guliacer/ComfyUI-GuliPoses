## GG 姿态库 v1.0.0 · 首个公开版本

在 ComfyUI 节点里直接翻白模姿态图库，选好姿态和视角就出图。288 组人体姿势 × 5 个视角 = 1439 张，全部内置在节点画廊里。

### 附件说明

| 文件 | 用途 |
| --- | --- |
| `ComfyUI-GuliPoses.7z` | **离线安装包**，解压后把 `ComfyUI-GuliPoses` 目录放进 `ComfyUI/custom_nodes/`，重启即可。适合没有 git、或 `git clone` 拉不动的网络 |

> 如果网络能 clone，推荐直接 `git clone https://github.com/guliacer/ComfyUI-GuliPoses.git`——以后 `git pull` 只拉代码改动，不用整包重下。

### 这个版本有什么

- **三种取图方式**：固定选中 / 全库随机 / 范围内随机。参数跟着模式显隐，固定选中时只剩干净的三行。
- **界面全中文**：参数名、输出名、系列 / 分类 / 姿势名（288 + 26 条全部译完），不夹英文参数名和日文原文。
- **只输出一张「姿态图」**：姿态名和视角写在画廊徽标上，不占输出槽。也没有 seed——抽到满意的点一下缩略图就锁定。
- **随机也看得见结果**：执行完把真正抽中的姿态推回画廊并自动跳过去。
- **节点高度由你决定**：拉高节点，栅格真的多显示几行；拉过的尺寸写进工作流，切模式 / 切视角 / 换筛选都不会被吸回去。
- **可以导入自己的姿态图**：点「导入」、拖进面板或 `Ctrl+V`，自定义名称 / 分类 / 视角，自动并入下拉与随机池。
- **零额外依赖**：只用 ComfyUI 自带的 PIL / numpy / torch。

### 数据与体积

- 图库随仓库分发，clone 完就能用，不需要另找数据或跑重建脚本。
- 原图为 900×1200 **WebP**（q95），1439 张共 104 MB——PNG 要 343 MB，实测 PSNR 50.9 dB、最大像素差 8/255，肉眼看不出差别。
- 缩略图不入库：`poses/thumbs/` 为空时由节点在首次请求时用原图现生成（单张 57 ms，画廊懒加载），省掉 1439 个文件。

### 兼容性

- 旧工作流可直接打开：残留的多余输出槽在载入时自动清理；缺失的 `seed` 值被忽略，其余参数按位对应。
- 与 [ComfyUI-GuliNodes](https://github.com/guliacer/ComfyUI-GuliNodes) 对齐命名（节点 `GG 姿态库`、分类 `GuliPoses`、前端文件 `gg-*.js`），两个插件可共存、可单独安装。

### 数据来源

姿态图与原始数据来自 [anhao/ai-pose-gallery-zh](https://github.com/anhao/ai-pose-gallery-zh)（中文镜像），原作者 **ギア**（[@giaaibusi](https://x.com/giaaibusi)）。著作权归原作者，本插件只做本地索引与画布内浏览。代码以 MIT 开源，该协议不覆盖 `poses/` 下的图片。
